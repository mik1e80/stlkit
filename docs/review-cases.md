# STLKIT 检查范围与复现案例

STLKIT 输出有限范围的网格检查、采样射线距离和简单修复结果。它不输出可打印认证，不计算喷嘴适配、支撑、摆放方向、材料或切片工艺。`check_printability` 为保留兼容性的接口名称，其返回值仍按本页的网格语义解释。

## 同一个模型与不同场景输入

执行 `node scripts/review-cases.cjs`。脚本调用实际 CLI，保存原始 stdout 到 `examples/review/reports/`，并验证退出码与关键内容。输入 `examples/cube.obj` 为项目自建的 1×1×1 立方体，三个场景使用相同文件，按 LF 换行规范化文本的 SHA-256 见 `reports/summary.json`。

| 场景 | 喷嘴记录 mm | 支撑记录 | 用户给定参考阈值 mm | 采样最小厚度约 mm | 严格退出码 |
| --- | --- | --- | --- | --- | --- |
| A | 0.4 | off | 0.8 | 1 | 0 |
| B | 0.8 | on | 1.2 | 1 | 1 |
| C | 0.4 | on | 0.8 | 1 | 0 |

例如场景 B：

```sh
moon run cmd/main examples/cube.obj --nozzle 0.8 --supports on --min-thickness 1.2 --strict
```

喷嘴与支撑是**只记录、不参与判定的上下文**；阈值由使用者另行输入，不由喷嘴推导，不是工艺推荐。B 的警告来自参考阈值从 0.8 改成 1.2，而不是工具判断大喷嘴不能打印。A 与 C 仅切换支撑，几何报告一致；它既不证明支撑有用，也不证明无需支撑。支撑是否需要、是否有效，应使用相应切片软件及实际工艺验证。

退出 0 表示未触发已覆盖网格项及参考阈值的门禁，始终同时输出“工艺未评估”和“不构成可打印结论”。网页也将喷嘴、支撑标为仅记录。

## 采样最小值会漏掉真实薄处

`examples/review/sampling-blindspot.obj` 是明确为暴露算法边界而安排面顺序的自建反例，不是随机语料或精度基准。它包含一个单位立方体和一块 1×1×0.05 薄板。立方体表面细分为 3072 个三角形，薄板有 12 个面，合计 3084 个三角形。保持两个闭合零件的几何，只把薄板面排到默认 1000 次采样未选中的编号。

```sh
moon run cmd/main examples/review/sampling-blindspot.obj --samples 1000 --min-thickness 0.1 --strict
moon run cmd/main examples/review/sampling-blindspot.obj --samples 3084 --min-thickness 0.1 --strict
```

第一条报告采样最小厚度约 1 mm、退出 0；第二条约 0.05 mm、退出 1。实际输出分别保存为 `sampling-1000.txt` 和 `sampling-all.txt`。第二个预算在本例覆盖了每个面，仍不等于覆盖面内所有位置，也不构成任意模型的全局厚度算法。

算法按三角形编号确定性取样，不按面积加权；沿几何法线反向取首个射线命中，结果受面顺序、采样数、几何朝向、浮点精度及起点偏移影响。默认预算 1000；CLI 的 `--samples` 可取 1..100000。提高预算可能发现更多薄处，但不保证达到全局最小壁厚，时间约 O(samples×faces)，目前没有空间加速结构。

统一网格报告仅在非空、边计数闭合、无退化面、相邻绕向一致且总体有符号体积为正时取样。上述条件仍不能排除网格自相交、全部非流形顶点或多个壳层的朝向问题。低层 `check_thickness()` 由调用方负责核对前提；没有命中表示未评估，不表示实际厚度为零。

## 流式省去完整网格，总存储仍增长

`--stream-only` 只接收二进制 STL，分块读取，不调用全量解析、厚度和修复。它与会运行全量解析的 `--bench` 不同，且不接受几何门禁参数。

```sh
moon run cmd/main examples/review/cubes-64.stl --stream-only
```

| 模型 | 三角形 F | 顶点表项 V | 边记录 R |
| --- | --- | --- | --- |
| 1 个分离立方体 | 12 | 8 | 36 |
| 16 个分离立方体 | 192 | 128 | 576 |
| 64 个分离立方体 | 768 | 512 | 2304 |

流式保存坐标去重表与每个三角形的三条边记录，排序前包含重复边。一般存储为 O(V+R+chunk)，非退化三角形 R=3F，不能把 R 当成不同边的数量。排序和最终统计还可能使用临时存储。即使重复输入同一个立方体、V 不增长，边记录也从 36 增到 72；该行为另有库测试。

CLI 读取块为 256 KiB；调用方喂入更大的块时，扫描器也会暂存更大输入。`StlScanner::storage()` 返回实际逻辑项数、残留字节和单次缓冲峰值，不包括数组容量、哈希桶、对象头、分配器与运行时，**不是 RSS 或进程峰值内存测量**。64 个立方体的本例小于一个读取块，不能据此推算大文件的内存节省比例。

## 可复核的交付终点

- 有效的声明范围内输入产生网格、限定检查报告、可选简单修复及导出；非法数值与不支持的 3MF 必需扩展明确拒绝。
- 报告使用“采样最小厚度”和“网格检查”，不以无警告推断可打印；喷嘴和支撑未评估。
- 修复后重新检查；薄壁、网格自交、复杂洞和工艺条件不由自动补洞解决。
- 本页、README、接口文档和 `docs/submission.md` 使用同一范围。申报时须替换旧附件，不能只更新 GitHub。

所有新增模型由项目生成，采用 Apache-2.0；原有 17 个第三方 3MF 样例及完整 BSD-2-Clause 条款见 `THIRD_PARTY_NOTICES.md`。案例可复现不表示组委会已重新审核。
