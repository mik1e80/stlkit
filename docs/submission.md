## 项目简介

STLKIT 用 MoonBit 读取 STL、OBJ、3MF、PLY 的支持子集，检查边界边、非流形边、退化面、声明法线及相邻绕向，提供几何统计、确定性射线采样、简单网格修复、导出和 SVG 预览。库、CLI、网页复用同一份 MoonBit 实现。

目标是给 MoonBit 程序提供可复用的网格处理接口，并让使用者在进入切片流程前筛查部分几何问题。交付结果是限定范围的网格报告与修复后复核，不回答模型能否成功打印，也不替代切片软件或工艺验证。

## 核心功能及边界

| 能力 | 已实现 | 边界 |
| --- | --- | --- |
| 读取 | ASCII / 二进制 STL，OBJ，3MF 核心三角网格与组件变换，ASCII / 大小端 PLY | 不是完整 3MF 规范认证；不支持的必需扩展拒绝，材质等可选语义可忽略 |
| 拓扑复核 | 边界边、非流形边、退化面、声明法线及相邻绕向 | 不覆盖网格自相交、全部非流形顶点或全部壳层内外关系 |
| 厚度估算 | 确定性表面采样，沿内法线记录射线命中的距离与样本最小值 | 可能漏掉薄处，不是全局最小壁厚；方向、面顺序、样本预算和起点偏移均有影响 |
| 几何统计 | 面积、体积、包围盒、PCA 包围盒、连通部分及质量属性 | PCA 非最小体积包围盒；体积与质量属性需核对闭合和绕向前提 |
| 简单修复 | 删退化 / 重复面、简单环补洞、统一绕向、重算法线后再检查 | 不修复设计薄壁、复杂自交或全部复杂破洞 |
| 流式 | 二进制 STL 分块扫描，不保留完整文件和 Mesh | 仍保留顶点表和全部三角形边记录，总存储随规模增长 |
| 输出 | 网格报告、STL / OBJ / PLY、SVG、CLI 与网页 | 无刀路、切片、支撑规划或工艺可行性判定 |

内部网格为三角形列表，按坐标容差重建拓扑，不保留 3MF 的原始顶点身份。STL / OBJ / PLY 在本工具中按毫米解释，需要使用者确认；3MF 按单位声明换算。

## 针对审查意见的复现案例

执行 `node scripts/review-cases.cjs`，自动调用真实 CLI，检查退出码并生成原始报告。完整解释见 [范围及案例](review-cases.md)。

1. **同一模型的场景记录**：同一个单位立方体，场景 A 为喷嘴 0.4 mm、支撑 off、用户参考阈值 0.8 mm；场景 B 为喷嘴 0.8 mm、支撑 on、参考阈值 1.2 mm。采样值均约 1 mm，门禁变化只由阈值变化导致。单独把支撑由 off 改为 on，结果不变，因为喷嘴和支撑仅记录、未评估。报告不将任一场景判定为可打印。
2. **采样漏检反例**：单位立方体加 0.05 mm 薄板，通过明确安排面顺序，默认 1000 次采样报告约 1 mm；增加到 3084 次后约 0.05 mm。这证明样本最小值不能当成全局最薄处。
3. **流式内存边界**：1、16、64 个分离立方体分别保留 8、128、512 个顶点项和 36、576、2304 条边记录。存储 O(V+R+chunk)，不再宣称固定总内存或原附件中的 84.3% 节省比例；计数也不是进程内存测量。

## 差异性与参考关系

与成熟 Python 网格库 trimesh 存在格式、拓扑、厚度查询和修复能力交集，差异在于 MoonBit 实现、库 / CLI / 网页复用和限定检查报告。trimesh 也有厚度查询；不再宣称该能力独有，不用未验证的性能数字比较。

参考 trimesh 的 API 与模块组织，未移植其实现。核心几何使用 MoonBit core；3MF 实际依赖 `hustcer/fzip` 与 `Milky2018/xml`，CLI 另用 `moonbitlang/x` 和 `moonbitlang/async`，因此不将本库整体描述成零第三方依赖。

项目采用 Apache-2.0。17 个外部 3MF 模型来自 3MF Consortium，来源、完整 BSD-2-Clause 条款及免责声明随仓库保留；新增案例由项目自建。许可证及参考范围见 `THIRD_PARTY_NOTICES.md`。
