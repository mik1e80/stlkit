## 项目简介

STLKit 使用 MoonBit 实现限定范围的模型读取、三角网格复核、几何分析、确定性射线距离采样、简单修复、导出和 SVG 预览。提供库、CLI 和浏览器网页，三种入口复用相同核心代码，供 MoonBit 应用集成及进入切片流程前的几何筛查。

| OBJ | Wavefront Advanced Visualizer 3.0 Appendix B1 多边形几何 | v/vn/vt/f、各表正负索引和四种一致面引用、平面简单多边形三角化；无 vt 的纹理引用、缺字段、越界及非单位 w 失败 | 不保存 UV/材质/分组/平滑语义，不实现自由曲面、点线场景、续行或顶点颜色扩展 |
| PLY | Greg Turk PLY 1.0 三角网格 | 三编码、完整唯一 format、x/y/z schema、声明类型及整数范围、list、索引和 EOF 检查；非法 header、短面、截断和多余正文失败 | 不保存颜色/法线，不接受仅点云；显式逐行兼容不放宽 header/类型 |

精确支持子集、拒绝条件、参考链接、资料权利与测试映射见 [格式兼容性说明](format-compatibility.md)。Core 1.3.0 是本次固定参考，不以共用命名空间或样例读取成功宣称 ISO 符合性或完整 Core 1.4.0 支持。

库可显式选择 `parse_3mf(data, compatibility=true)` 恢复旧包定位回退，但不放宽模型 XML、Id、索引和必需扩展。自动入口、CLI 和网页均保持默认严格读取，兼容读取成功不作为标准包合规证据。

## 核心功能及边界

1. 网格复核：边界边、非流形边、退化面、已保留声明面法线反向和相邻绕向，按共享边分量报告方向。未实现完整自交、非流形顶点与精确壳层判定。
2. 几何统计：面积、体积、AABB、PCA OBB、连通部分、欧拉数及质量属性。PCA 非最小体积；质量属性仅在前提满足时输出，不证明没有自交。
3. 射线采样：报告命中数及样本距离，不保证全局最小壁厚；面顺序、预算、法线和偏移影响结果。楔形侧面首命中距离不等同于竖向厚度。
4. 简单修复：删重复/退化面、简单边界环补洞、绕向及法线处理；导出后重读复核。不自动解决所有破洞、设计薄壁和复杂自交。
5. 导出与预览：STL、OBJ、PLY、SVG；可合用 --fix 和 --svg，严格退出码根据最终复核结果决定，文件生成不等于风险消除。
6. 二进制 STL 分块统计：不保留完整 Mesh，但顶点表与全部边记录仍增长，总存储 O(V+R+chunk)。CLI 字段估算不是进程内存实测。

STL/OBJ/PLY 坐标由调用方确认，本工具按毫米解释；3MF 按声明单位换算。拓扑默认按 1e-6 mm 坐标格子重建，不保留输入共享顶点身份。喷嘴、支撑仅记录上下文，不作工艺判断；结论不构成可打印认证。

## 差异性、参考与依赖

与 trimesh 在格式、拓扑、厚度查询和修复方面有交集，差异为 MoonBit 实现、库/CLI/网页共用及限定范围的复核工作流。不宣称厚度独有、生态唯一或未经验证的跨项目性能优势。

参考 trimesh 的 API 与模块组织，未移植其实现。核心几何使用 MoonBit core；3MF 依赖 hustcer/fzip 和 Milky2018/xml，CLI 另用 moonbitlang/x 和 moonbitlang/async。因此“库本体零第三方依赖”不适用于项目整体。

## 测试与完成标准

获批的 0.1.4 基线为 Wasm、Wasm-GC、JS、Native 四后端各 352 项测试；已发布 0.2.0 为各 385 项。本批修订的测试命令、数量和实际入口证据另见 [验收交付说明](acceptance-delivery.md)，不将旧版本测试数作为当前工作区的验证结果。格式边界在内存中自行构造；实际 CLI 和网页使用同组负向字节样例验证默认严格入口。

原有 37 个模型全部复测，总计 67 次读取、5 组修复后重读及 10 组固定预算采样。解析值模型与外部回归快照分开解释，坏输入被拒绝属于负向测试通过，不将所有模型写成“检查无问题”。Cura 4.5 私有 XML 根由严格入口拒绝，不能宣称完整 Cura 工程兼容。

10万、50万、100万面历史记录保留原始测量环境，不冒充 0.1.4 重新计时；CI 重新生成 10万面连通网格验证全量/整块/分块计数一致。命令、哈希、原始输出和失败反馈统一见 [COMPARISON.md](../COMPARISON.md)。

完成标准：公开子集具备正负测试，合法范围内输入产生网格与限定报告，列明非法/不支持输入明确失败，修复后重读复核，文档与申报不将有限结果包装为完整标准认证或可制造结论。
