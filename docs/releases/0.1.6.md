# 0.1.6 — 发布包安装验证修正

2026-10-28。包含 [0.1.5 的解析可靠性维护](0.1.5.md)，核心算法不变；修正独立安装测试对版本的选择和核对。

0.1.5 发布后核查发现，consumer 示例原先声明 0.1.4，`moon add` 缺少 `--upgrade` 时可能保留原有版本，测试输出中的请求版本不足以证明实际安装版本。0.1.6 显式升级指定版本，并在编译解析依赖后读取安装包的 `moon.mod`，断言其版本与请求一致，再执行四后端测试。固定示例仍从旧依赖出发，以持续覆盖升级路径。0.1.5 已发布包及标签不移动。

第一批实际交付：STL / OBJ / PLY / 3MF 统一可配置资源预算、3MF ZIP 预检及 CRC、重复组件展开限制、CLI 读取前限额检查、网页限额、确定性变异独立 CI、公开包独立 consumer，以及预算、变异、维护和路线文档。未加入 IndexedMesh、BVH、自相交或 JSON CLI。

验证：四后端各 371 项库测试；四后端各 10,000 次确定性变异摘要一致；67 次模型读取、5 次修复重载、10 次厚度对照、100k 全量/分块一致性、真实 CLI 与网页回归通过。新增代码和种子 Apache-2.0，无新外部下载模型；已有外部来源、完整许可和哈希检查通过。修正后的 consumer 还独立验证真实 0.1.5，发布后使用同一脚本核对 0.1.6。

安装：`moon add mik1e80/stlkit@0.1.6`。复核：`moon run scripts/consumer-smoke.mbtx 0.1.6`。脚本每次创建全新目录，安装指定 Mooncakes 版本，无工作区源码路径依赖；正式 Release 触发独立 consumer CI。
