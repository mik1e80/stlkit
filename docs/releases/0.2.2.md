# 0.2.2 — 固定独立脚本依赖

2026-10-31。0.2.1 包与 v0.2.1 标签保留不动；本次修正公开包验收时发现的脚本复现缺陷。核心几何与公开 API 相对 0.2.1 无变更，继承其边界、数值、修复与许可改进。

独立 .mbtx 脚本不自动继承根 moon.mod 的依赖版本。更新注册表后，它们原本会选择新发布的 async 0.22.7，该版本引用旧 SDK 不具备的 moonbitlang/core/async，导致验证脚本启动失败。全部 11 个独立脚本现同时固定 async 模块及子包为 0.22.1、x 子包为 0.5.5，禁止依赖隐式追随最新注册表。

README、安装示例、consumer 默认版本和验收交付目标同步为 0.2.2。0.2.1 的打包检查与服务端发布确实成功，但首次独立消费者验证被脚本依赖漂移阻断，未创建对应 GitHub Release，不将它误报为完整交付。

固定源码 `3a85bb4464d18dbc64a1cddd314724d5551fc206` 已重新通过 check/build/test、四后端各 417 项、Quick Start、许可、网页与模型回归。Mooncakes 发布返回 200 OK，本机公开包四后端 consumer 通过后创建 v0.2.2 Release；随后 Release 的 Linux / Windows 四后端独立安装矩阵也通过。完整 CI、包安装证据见 [验收交付说明](../acceptance-delivery.md)；API 与兼容变化见 [0.2.1 说明](0.2.1.md) 和 [受检 API](../checked-apis.md)。

工具链仍为已验证精确白名单 0.10.17+d971670cd / 0.10.18+6c83a7f62，验收最低要求为 0.10.16；不据此宣称已验证所有编译器。脚本预算、硬链接/路径竞态、采样和不完整几何语义等已知边界保持。
