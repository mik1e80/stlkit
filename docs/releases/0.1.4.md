## 代码修改

- OBJ 建立 vt 表，检查四种一致面引用的独立索引范围；缺声明、0、越界、空段、多斜杠、非十进制索引失败。v/vn/vt 缺字段和非单位 w 失败；UV 和材质不保存。
- PLY 验证 ASCII 整数词法及类型范围，计数/内部索引防溢出，list 长度与 face 索引须声明整数。未知/不完整 header、额外字段及 0/1/2 顶点的面失败。
- 3MF 默认检查根关系与内容类型：唯一内部模型关系、正确 MIME、存在目标和无歧义声明。模型按完整 Core URI 与局部命名空间解析，验证对象 Id 和已处理几何层级；保留引用、单位、变换、有限数和必需扩展检查。
- `parse_3mf(data, compatibility=true)` 显式恢复旧包定位；默认 parse_3mf、parse_mesh、CLI 和网页不自行回退。该选项不放宽 XML/几何。

输入接受范围收紧。依赖未声明 vt、错误 PLY 类型/短面或猜测 3MF 定位的调用方应修复输入；仅有明确旧包定位需求时显式启用兼容。旧包与标签保留，不移动标签。
