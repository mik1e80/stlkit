# 0.2.3 — Web 单次计算、数值边界与来源校验

第二轮维护修订，兼容保留原函数签名；新增受检面积与最近点接口及 Web analyze_bundle / fix_bundle。Web 文件读取增加请求代次并限制为默认 16 MiB、硬上限 32 MiB / 50 万面；预览错误独立展示，CLI 不再保存失败注释并声称成功。

法线与面积采用独立边缩放和指数恢复，无法可靠表示时通过受检 API 明确拒绝；旧最近点无结果哨兵变为 Infinity。多边形增加固定检查次数预算；SVG paint 使用允许列表。这些属于行为修正，依赖旧无限制颜色、旧浏览器上限或旧有限最近点哨兵的调用方须查看 [受检 API](../checked-apis.md)。

来源检查实际计算 Git Blob 和 SHA-256，限定已审查的 CC0 / BSD 许可与完整法律文本；CI 验证实际包清单并运行缺许可/错误 blob/非法许可/混入模型的负向案例。源码模型仍在 GitHub 固定版本，未加入未知许可文件或新第三方几何实现。

实现、验证、Actions 与供应链状态见 [第二轮整改](../round2-remediation.md)。当前为发布候选，正式固定 SHA、CI、包与两平台独立安装完成后再补证据；旧标签不移动。

补洞不检测补丁与其他非邻接面相交；BVH、完整自交、非流形顶点、Worker / 取消仍在后续路线。数值和浏览器预算不提供所有病态几何、设备上的误差、时限或内存保证。
