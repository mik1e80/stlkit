# 0.2.1 — 验收修订与可复现交付

2026-10-31。将 0.2.0 之后的边界、数值和许可证修订汇总为新包，保留全部旧标签及历史测量。精确源码 SHA、CI、正式发布及独立安装结果见 [交付证据](../acceptance-delivery.md)。

- 体积、重心和惯量改用局部坐标与补偿求和；稳定向量范数和缩放 PCA。增加必要数值检查，无法可靠计算时不输出可用质量属性。
- 新增受检验证、修复、STL 导出、SVG，以及 RepairLimits 和面积加权厚度采样。旧签名保留；迁移与错误行为见 [受检 API](../checked-apis.md)。
- 简单平面凹边界采用耳切补洞，分支、自交、非平面及超预算环拒绝。厚度从表面排除来源面查询，去掉可能跨越局部薄壁的全局 inset。
- CLI 防规范化路径及真实目标冲突；导出前解析、写盘后重读，最终结论和 SVG 使用实际文件。SVG 属性转义、参数校验、最多 20000 面预览；CLI / 网页限制厚度工作预算。
- OBJ 不支持几何拒绝、PLY 重复属性和固定 header 预算、3MF 唯一有序容器及镜像/缩放/剪切/奇异变换回归。
- 17 个官方模型补齐固定上游路径、内容锚点、Git blob、SHA-256 和完整 BSD；15 个外部来源保留完整许可。修复浏览器许可证链接，包内容保留必要声明。
- README 的单位立方体、缺面修复和 JSON 命令纳入 Linux / Windows CI；库最小示例参与单元测试，独立发布包 consumer 覆盖新增 API。

官方验收最低要求 moonc 0.10.16；本机实际验证 0.10.17+d971670cd，Linux / Windows CI 为 0.10.18+6c83a7f62。使用精确白名单，不把最低要求当作所有后续编译器均受支持。版本升级后的最终提交必须重新跑 check/build/test，不能复用旧 SHA 的绿色状态。

发布准备时本机四后端各 417 项通过（比此前 416 项新增一个可执行 README 库示例），Quick Start、许可和网页回归通过，公开接口生成无 API 差异。moon package 清单保留根许可证、完整 BSD/CC0、两份来源清单与浏览器依赖许可，排除模型体积文件及构建缓存。publish --dry-run 的打包解压与检查通过，服务端返回 202 “Dry run completed successfully. No changes were made.”；本机旧版 moon 将该 202 判为非零退出，因此不把它记作普通退出码通过，也不据此声称已发布。最终包可用性必须另由真实发布和独立安装证明。

已知边界：硬链接、路径检查后替换竞态与原子写入未解决；不保证任意病态尺度误差界。厚度非全局最薄处，PCA 非最小体积盒。BVH、完整自相交/非流形顶点、完整 3MF 材质、MeshDocument、Web Worker 与取消仍在路线中。构建仍通过 latest 官方安装器加精确版本检查，尚非完整固定 archive 安装。

本批新增代码、测试和解析值模型采用 Apache-2.0；未加入许可未知的新网络模型。模型与依赖的独立许可仍适用。
