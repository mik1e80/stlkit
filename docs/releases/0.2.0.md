# 0.2.0 — JSON 协议、结构化解析错误与索引网格

2026-10-28。接续 0.1.6 的可靠性维护，交付路线的 API/CLI 和独立索引网格初版。历史包与标签保留。

- CLI `--json` 输出 schema_version=1 文档；明确参数、读取/解析、严格复核和内部执行退出码。保留中文报告；JSON v1 仅检查，不与修复/导出/基准/分块模式组合。
- `inspection_json` 提供相同库报告；未评估质量属性使用 null，计算溢出使用 null 并强制复核，不将有限采样或网格检查称作可打印认证。
- `parse_mesh_checked` 新增四类 ParseError，旧字符串接口保留。不按本地化错误文案猜测精细子类型或行号。
- `IndexedMesh` 通过私有数组快照保持有限坐标/有效索引，支持 Mesh 往返、逐面法线、几何统计和拓扑兼容接口。近坐标不自动焊接；拓扑兼容接口暂时展开旧 Mesh。
- 增补真实 CLI JSON 回归、四后端公共 API 回归、100k 网格内存对照、版本核对后的公开包 consumer。新增代码和自建网格 Apache-2.0；未下载新第三方模型。

IndexedMesh 转换包含原网格与去重表，实测峰值高于仅生成 Mesh，不能宣传为全流程内存优化。BVH、自相交、MeshDocument、批量 CLI、Web Worker 和取消仍是后续工作。

本地验证：四后端各 385 项库测试通过；20 组真实 JSON CLI（18 Native + 2 Wasm）、现有中文 CLI 与网页回归通过；67 次读取、5 次修复重载、10 次厚度对照及外部来源/许可/哈希检查通过。四后端各 10,000 次变异中新旧解析入口接受行为一致，摘要保持 accepted=2560 / rejected=7440 / digest=2865708385。100k 内存原始六次结果见实测文档，不复用旧性能结果冒充新测试。
