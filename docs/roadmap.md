## 0.2.0 本批交付

20 组真实 CLI JSON 回归（18 Native + 2 Wasm）、公开接口黑盒/四后端测试、索引几何与快照边界、自建 100k 网格转换实测。转换峰值升高的结果已记录，未包装成内存优化。IndexedMesh 仍需后续原生索引拓扑算法；BVH、模型语义及 Web 产品功能按依赖顺序继续推进。

GitHub 后续任务：[API / IndexedMesh #1](https://github.com/mik1e80/stlkit/issues/1)、[BVH #2](https://github.com/mik1e80/stlkit/issues/2)、[几何诊断 #3](https://github.com/mik1e80/stlkit/issues/3)、[语义 / 产品 / 生态 #4](https://github.com/mik1e80/stlkit/issues/4)；[版本里程碑](https://github.com/mik1e80/stlkit/milestones)。

每个阶段要求代码、测试、文档一起完成，才在 README 标为支持。既有大模型测量保留原日期和机器环境，本次没有重测的 500k / 1m 性能不挪作新版本数据。未来复杂算法按独立里程碑交付，不一次重写核心。
