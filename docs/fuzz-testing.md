# 确定性解析器变异测试

工具位于 `tools/fuzz/`，启动脚本为 `scripts/fuzz.mbtx`。种子由本项目独立编写并在内存生成，采用仓库 Apache-2.0 许可证：单三角形 Binary / ASCII STL、OBJ、ASCII PLY，以及带关系表和内容类型表的 stored ZIP 3MF。**没有新增外部下载模型**；既有第三方语料的来源和完整许可仍见 `THIRD_PARTY_NOTICES.md` 和模型目录。

```sh
moon run scripts/fuzz.mbtx all 1000
moon run scripts/fuzz.mbtx all 10000
# 单独重现第 631 号输入（保留从固定种子到该编号的随机状态）
moon run scripts/fuzz.mbtx js 1 631
```

固定 LCG 初值为 `0x53544c4b`；五种格式按编号轮换。十类操作为截断、替换、删除、插入、尾随字节、重复整个输入、定向坏计数/索引/结构、长行、保留原始正向种子、追加极值数字。定向 Binary STL 还包含合法但以 ZIP / PLY 魔数开头的 opaque header，防止内容路由错误。当前 3MF 随机字节变异多数先被 ZIP / CRC 拒绝，XML 定向种子只覆盖重复对象 Id；并不等于覆盖全部 XML、压缩算法或 OPC 状态。

每个输入调用直接解析与自动入口。成功结果要求有限坐标、面数不过预算，且自动入口也接受；二进制 STL 另比较整文件和两块扫描的接受状态与面数。失败须返回非空说明。工具在解析前输出 `CASE` 编号，四后端对比接受数、拒绝数及基于面数的结果摘要；摘要相同不证明坐标或全部错误消息逐字相同。

小预算固定在源码：8 KiB 输入、128 面、256 顶点声明/角、2,048 list 项、64 角多边形、32 KiB 解压、16 ZIP 条目、8 层组件、256 实例访问、8,192 记录/token、1 KiB 行、32 层 XML。启动器为每个后端的**整轮构建及运行**设置 120 秒超时，不是逐输入 120 秒；日志直接写入 `_build/fuzz-<backend>.log` 和 stderr 日志，进程失败或超时后仍可查最后一个 CASE。

独立的 `fuzz.yml` CI 每次相关源码变更运行四后端各 1,000 次，可手动选择 10,000 次，失败时保留日志。回归库测试独立执行，不以随机输入替代已知答案断言。发现缺陷应先缩减为固定案例，加入普通测试，再修复。
